# Experience Lab：艺人资产与视觉方向

## 目标

Concert Passport 不应首先像一个管理演出的工具，而应像一件用户愿意保存、反复观看和主动发到社交媒体的个人纪念品。

这次原型把体验拆成两类结果：

- 页面体验：在浏览过程中制造期待、临场感和收藏欲。
- 分享成品：离开产品后仍然成立，能够被一眼认出是“我的这场演出”。

页面不依赖大段情绪文案。情绪主要由艺人影像、唱片资产、场馆、时间、动势和个人状态共同产生。

## 融入 Concert Passport 的方式

ITZY 不是独立的宣传落地页，而是完整产品动线里的一场“演出世界”：

1. **Discover**：用即将发生的演出和真实艺人资产建立期待，用户先看到“我可能想去的现场”。
2. **Find shows**：按艺人追踪一段巡演，或按旅行地区和日期寻找演出。
3. **Show world**：进入某一场后，由这次巡演自己的视觉、唱片、舞台、场馆和城市资产构成体验。
4. **Saved**：收藏表达“我想去”，保存的是行动意图，不伪造购票、同行者或观看数据。
5. **Passport**：只记录真正发生过的演出，成为跨艺人、跨城市的个人现场档案。
6. **Share**：从真实演出和个人记录生成社交媒体成品，把用户带回发现新的现场。

这条动线把 upcoming discovery 与情绪价值放在同一件产品里：寻找演出不是后台工具，回忆也不是脱离真实场次的装饰。

## 产品文案规则

- 产品界面只说用户此刻需要知道、需要做或已经发生的事。
- 不在页面解释设计意图、资产策略或用户画像；例如“同一位艺人，不只有一张封面”属于设计讨论，不属于产品文案。
- 不使用虚构的朋友、热度、稀缺性或个人数据制造戏剧性。
- 状态文案必须可核验：日期、城市、场馆、售票状态和来源都来自真实数据。
- 情绪由素材、构图、动势与用户自己的现场记录产生，文字保持克制。

## 四层资产结构

### 1. 艺人主资产

巡演主视觉、官方艺人照、专辑与单曲封面、舞台摄影、官方 set list 等，是页面的第一视觉语言。产品界面退到后面，不用统一模板抹平不同艺人的个性。

### 2. 演出现场资产

场馆外观、城市夜景、舞台灯光、座位与票面信息让体验落到真实的一晚，而不是抽象的艺人资料页。

### 3. 用户个人资产

用户拍摄的照片、视频、票根、座位、同行者和现场片段最终应该进入构图。它们决定分享图是个人记忆，而不是官方海报的二次排版。

### 4. 程序化视觉资产

光场、颗粒、折射、色散、动态裁切和节奏化排版用于连接真实素材。它们不能喧宾夺主，也不能成为通用的“AI 风格背景”。

## 动态色彩系统

颜色不从固定的粉色品牌模板开始，而从每次演出的官方资产提取：

- 主色来自巡演主视觉和专辑封面。
- 对比色服务于倒计时、行动按钮和分享标题。
- 中性色保证艺人照片与用户照片不被滤镜污染。
- Concert Passport 的品牌只保留在字体关系、版式节奏和极少量固定标识中。

这次 ITZY 原型使用《TUNNEL VISION》的黑白、金属和摩托车影像作为硬朗基底，再从《MOTTO》的粉、蓝、银中释放光谱色。它不是“年轻女性等于粉色”，而是从艺人这次 campaign 的真实张力出发。

## 动效语法

- 入场：主视觉以舞台开幕式的裁切揭示，不做模板化淡入。
- 滚动：图像层、巨型文字和信息以不同速度建立空间感。
- 交互：城市、日期和保存状态以小范围、有因果的形变回应用户。
- 程序化光场：只负责临场空气和景深，不持续抢占注意力。
- 无障碍：系统设置减少动态时，关闭 3D 光场和高幅度变换。

保留原生滚动，不为了“高级感”引入会破坏移动端手感的平滑滚动层。

## 分享输出

| 场景 | 比例 | 用途 |
| --- | --- | --- |
| Story | 9:16 | Instagram Story、短视频封面 |
| 小红书 | 3:4 | 小红书图文首图 |
| Square | 1:1 | 社交动态、头像式收藏卡 |

分享图不是页面截图，而是独立渲染的高清成品。后续应允许用户在同一批真实资产中选择主图、裁切、色彩和信息密度，并保留足够稳定的 Concert Passport 识别结构。

## 资产来源优先级

1. 艺人、经纪公司、巡演和主办方官方页面。
2. 官方音乐平台的发行封面与编辑资产。
3. 场馆和城市的官方媒体库。
4. 许可明确的开放图库，例如 Wikimedia Commons。
5. 用户已授权上传的现场内容。
6. 原创或程序化生成的辅助纹理、光场和构图素材。

原型阶段允许远程引用以快速探索；产品化前必须完成授权确认、来源记录、本地转存、响应式裁切和失效兜底。素材版权和缓存管线是生产约束，不应在概念阶段提前压低设计上限。

## 当前原型使用的样本

- ITZY / JYP 官方活动与艺人信息。
- Live Nation Taipei 官方巡演主视觉与场次信息。
- Apple Music 的《TUNNEL VISION》《MOTTO》和 set list 编辑资产。
- 授权明确的 Taipei Arena 夜景。
- 程序化舞台光场和粒子层。

## 下一轮判断标准

下一轮不以“页面是否更丰富”为标准，而检查：

- 不看文案，能否立刻感到这是 ITZY 的这一次巡演。
- 用户是否能从浏览自然过渡到保存和分享，而不是被一个工具按钮打断。
- 分享图离开产品上下文后，是否仍像一件值得发布的内容。
- 换成另一位艺人后，页面是否真的会换一种性格，而不是只替换封面和主题色。
